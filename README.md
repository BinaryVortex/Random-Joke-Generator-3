# Random Joke Generator

A simple web application that generates random jokes using the JokeAPI.

## Description

This project is a fun, lightweight web app built with HTML, CSS, and JavaScript. It fetches random two-part jokes from the JokeAPI and displays them on the page. Click the "Generate Joke" button to get a new joke!

## Features

- Fetches jokes from a public API
- Clean and responsive design
- No NSFW content
- Easy to use

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Use

1. Clone the repository
2. Open `index.html` in your browser
3. Click "Generate Joke" to get a new joke!
